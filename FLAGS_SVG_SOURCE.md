# Drapeaux SVG — Bleus 3000 V1.1.36

Bleus 3000 utilise des drapeaux SVG 4:3 issus de **flag-icons**, épinglés sur la version 7.3.2.

- Projet : `lipis/flag-icons`
- Format utilisé : `flags/4x3/<code>.svg`
- Résolution Bleus 3000 : noms français / anglais → code ISO 3166-1 alpha-2.
- Cas football non-ISO gérés : Angleterre, Écosse, Pays de Galles, Irlande du Nord.
- Le fichier `Bleus_3000_V136_flags.js` contient la table de normalisation et génère les URLs SVG.

L'objectif est d'éviter les variations d'affichage des emoji de drapeaux selon Windows, macOS, Android ou iOS.
