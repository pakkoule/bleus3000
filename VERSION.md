# Bleus 3000 — V1.1.25

Ajout explicite des accomplissements depuis la fiche joueur en mode modification.

- menu « Choisir un accomplissement » dans l’éditeur d’une tuile ;
- bouton `+ Ajouter` ;
- seuls les accomplissements affiliés au référentiel Sélections sont proposés ;
- valeur numérique facultative par accomplissement (ex. Capitanat ×36) ;
- retrait individuel avec bouton × ;
- conservation de plusieurs accomplissements sur une même fiche ;
- aucune migration Supabase nécessaire ;
- moteur de recherche V1.1.24 inchangé.
